# EcoViz User Manual

## **Overview**

### General Idea of EcoViz

EcoViz is a software tool designed for the visual analysis and photorealistic rendering of forest landscape model simulations. Developed in C++ with the Qt6 framework, it allows users to explore complex ecological data through an interactive 3D interface. The primary purpose of EcoViz is to visualize and compare simulated landscape trajectories, such as those generated by the iLand model, under different conditions (e.g., climate scenarios) and across various spatial scales. It supports both symbolic rendering for clear differentiation of data and photorealistic rendering for realistic depictions of the environment.

### What You Can Do

With EcoViz, you can perform a variety of visualization tasks:

-   **Side-by-side comparisons**: Display two scenarios simultaneously (e.g., a baseline climate vs. a climate change scenario) for direct comparison.

-   **Multi-scale analysis**: Visualize landscapes at different scales, from a broad landscape view (\~1000 ha) down to the detailed stand level (\~6 ha).

-   **Temporal analysis**: Use a timeline to observe forest dynamics over time, such as the effects of disturbances and subsequent recovery.

-   **Photorealistic rendering**: Export scenes to Mitsuba, an open-source, physically-based rendering engine, to create high-quality, realistic images.

-   **Symbolic rendering**: View vegetation with species differentiated by color for clear, analytical visualization of species composition and distribution.

-   **Transect analysis**: Select a cross-section of the terrain to view a detailed profile of the vegetation.

## **Starting EcoViz**

EcoViz is launched from the command line, which allows you to specify the data to be loaded. The demo package includes a convenience script, **`start_ecoviz_wbt.cmd`**, which starts the software with the Klausbachtal demo project. In this demo, the baseline simulation appears in the left view and the climate change scenario in the right.

### Command-Line Parameters

You can run the executable (**`ecoviz.exe`** on Windows or **`./viz/ecoviz`** on Linux/macOS) with the following parameters to load your own data:

-   **`-prefix <basename>`**: Loads the same dataset for both the left and right displays. For example:

    ```         
    ./viz/ecoviz -prefix ecoviz ../../data/test2  
    ```

-   **`-lprefix <basename>`**: Specifies the base filename for the dataset displayed in the **left** window.

-   **`-rprefix <basename>`**: Specifies the base filename for the dataset displayed in the **right** window.

## **Using the UI**

The EcoViz interface is divided into multiple panels, including a 3D scene view, a transect view, and a timeline.

### Mouse and Keyboard Controls

-   **Rotate View**: Hold down the **right mouse button** and move the cursor in the 3D scene view.

-   **Zoom**: Use the **mouse wheel**. Alternatively, use the **up/down arrow keys**.

-   **Change Focal Point**: **Double-click** with the **right mouse button** on a point in the terrain to center the view on that location.

-   **Select a Transect**: Hold **Ctrl** and use the **left mouse button** to click two points on the terrain. These points define the start and end of the transect.

-   **Adjust Transect Width**: Use **Ctrl + mouse wheel**.

### Key UI Features

-   **Minimap**: Press the **'m' key** to toggle the visibility of the minimap. In the minimap, you can **left-click and drag** to move the current selection or **right-click and drag** to define a new viewing region.

-   **Link Views**: Use the **lock symbols** to synchronize the camera positions of the left and right views.

-   **Timeline**: At the bottom of the window is a media bar with controls to play, pause, or step through the simulation time-steps.

## **Adapting the View**

EcoViz provides several dialogs and menus to customize what is displayed in the scene.

-   **Plant Options**: This dialog allows you to show or hide individual tree species.

-   **Terrain Options**: Here, you can switch the camera mode between **Orbit** and **Flyover** and toggle contour/grid lines.

-   **View Controls**: This panel lets you save the current viewpoint to a file or load a previously saved viewpoint.

## **Rendering Images**

For high-quality, photorealistic images, EcoViz integrates with the Mitsuba rendering engine.

### Exporting Scenes to Mitsuba

1.  From the **File menu**, open the **Export Mitsuba** dialog.

2.  **Specify an Output Path**: This is the directory where Mitsuba's scene files will be saved.

3.  **Set the Resources Path**: This path must point to the directory containing the 3D tree models and textures. In the provided package, this path should be set to `resources/mitsuba`.

After exporting, EcoViz generates a set of files, including a JSON file, that Mitsuba uses to render the scene.

## **Using EcoViz with Your Data**

### Data Format

EcoViz loads vegetation data from two file formats: a text-based **`.pdb`** and a binary **`.pdbb`**. The binary format is preferred as it loads faster and uses less disk space. A converter tool, **`ecosimtobin`**, is provided to translate text files to their binary equivalents.

#### Text-Based PDB File Format (`.pdb`)

This format is human-readable and stores data as text, with fields separated by whitespace.

|                                       |                     |             |                                                             |
|---------------------------------------|---------------------|-------------|-------------------------------------------------------------|
| **Description**                       | **Data Type (C++)** | **Example** | **Notes**                                                   |
| PDB File Version                      | String              | `"3.0"`     | Indicates the file format version.                          |
| World Origin X                        | Double              | `253323`    | The X-coordinate of the world origin in metric coordinates. |
| World Origin Y                        | Double              | `20353`     | The Y-coordinate of the world origin in metric coordinates. |
| Time Step Number                      | Integer             | `1`         | The simulation year for the data.                           |
| Total Number of Trees                 | Integer             | `100000`    | A placeholder for the total tree count.                     |
| **Tree Data (one line per tree)**     |                     |             |                                                             |
| Tree ID                               | Integer             | `1`         | Unique identifier for the tree.                             |
| Species ID                            | Char                | `piab`      | Identifier for the tree species.                            |
| Position X                            | Float               | `100`       | X-coordinate of the tree (m) relative to origin.            |
| Position Y                            | Float               | `35.5`      | Y-coordinate of the tree (m) relative to origin.            |
| Height                                | Float               | `20.7`      | Height of the tree (m).                                     |
| Canopy Radius                         | Float               | `3.23`      | Radius of the tree's canopy (m).                            |
| DBH                                   | Float               | `22.1`      | Diameter at breast height (cm).                             |
| Status                                | Integer             | `0`         | Tree status: 1 if dead, 0 if alive.                         |
| **Cohort Data (one line per cohort)** |                     |             |                                                             |
| Position X                            | Float               | `2.5`       | X-coordinate of the cohort cell center (m).                 |
| Position Y                            | Float               | `1234`      | Y-coordinate of the cohort cell center (m).                 |
| Species ID                            | Char                | `lade`      | Identifier for the cohort species.                          |
| DBH                                   | Float               | `0.23`      | DBH of the cohort (cm).                                     |
| Height                                | Float               | `1.4`       | Height of the cohort (m).                                   |
| Represented Stem Number               | Float               | `23`        | Number of trees represented by this cohort.                 |

An example `.pdb` file starts like this:

```         
3.0 4570108 5269625 1 423947 4109621 lade 595 97 15.0974 2.5 27.4414 0 ....  
```

#### Binary PDBB File Format (`.pdbb`)

This is a more compact, binary representation of the data that significantly improves performance.

|                          |                   |                  |                                                                     |
|--------------------------|-------------------|------------------|---------------------------------------------------------------------|
| **Description**          | **C++ Data Type** | **Size (Bytes)** | **Notes**                                                           |
| Length of Version String | `int`             | 4                | The number of characters in the version string (e.g., 3 for "3.0"). |
| Version String           | `char[]`          | `slen`           | The version string itself, not null-terminated.                     |
| World Origin X           | `int64_t`         | 8                | The X-coordinate of the model's world origin.                       |
| World Origin Y           | `int64_t`         | 8                | The Y-coordinate of the model's world origin.                       |
| Time Step Number         | `int`             | 4                | The simulation year.                                                |
| Total Number of Trees    | `int`             | 4                | The total count of individual trees.                                |
| **Tree Data Block**      |                   |                  | A contiguous block of tree data structures.                         |
| Species Code             | `char[4]`         | 4                | 4-byte ASCII code for the tree species.                             |
| Position X               | `int`             | 4                | X-coordinate of the tree.                                           |
| Position Y               | `int`             | 4                | Y-coordinate of the tree.                                           |
| Height                   | `float`           | 4                | Height of the tree.                                                 |
| Canopy Radius            | `float`           | 4                | Radius of the tree's canopy.                                        |
| DBH                      | `float`           | 4                | Diameter at breast height.                                          |
| Status (Dummy)           | `int`             | 4                | Tree status: 1 if dead, 0 if alive.                                 |
| Total Sapling Cohorts    | `int`             | 4                | The total count of sapling cohorts.                                 |
| **Sapling Data Block**   |                   |                  | A contiguous block of sapling data structures.                      |
| Position X               | `int`             | 4                | X-coordinate of the sapling cohort.                                 |
| Position Y               | `int`             | 4                | Y-coordinate of the sapling cohort.                                 |
| Species Code             | `char[4]`         | 4                | 4-byte ASCII code for the sapling species.                          |
| DBH                      | `float`           | 4                | DBH of the sapling cohort.                                          |
| Height                   | `float`           | 4                | Height of the sapling cohort.                                       |
| Number of Plants         | `float`           | 4                | Number of plants represented by this sapling cohort.                |
